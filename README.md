## 📋 خطوات التثبيت

> [!NOTE]
> البرنامج يعمل على **Windows 10 و Windows 11** فقط (64-bit)

1. **⬇️ تحميل الملف** — اضغط على زر التحميل أعلاه واختر `JudoManager-Pro-Setup.exe`
2. **🖱️ تشغيل المثبّت** — انقر على الملف مرتين لبدء التثبيت
3. **✅ اتباع الخطوات** — اضغط Next حتى اكتمال التثبيت
4. **🖥️ فتح البرنامج** — ستجد اختصار **JudoManager Pro** على سطح المكتب
5. **🔑 إدخال الترخيص** — أدخل مفتاح الترخيص الخاص بك للبدء
